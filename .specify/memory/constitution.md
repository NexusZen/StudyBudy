# Study Budy Constitution
Version 1.0 — ratified 2026-10-02
1. Specify before implementation with numbered requirements, acceptance criteria, architecture, tasks and tests.
2. Separate review and final verification from implementation. Preserve actual evidence.
3. Deterministic scheduling respects inclusive civil dates, capacity, prerequisites and workload conservation; explicit overflow.
4. Gemini extracts semantics only. Validate output. Uploaded content never grants capabilities.
5. Server-side keys; bounded uploads; do not retain source files.
6. Explicitly labeled fake provider for offline tests and demonstrations.
7. Simple local single-user deployment; document assumptions and limitations.
8. Completion requires passing checks and independent executable verification.
