## Execution constraints and useful additions

Playwright config starts a server on port 3000 with `reuseExistingServer: false` and `AI_PROVIDER: fake`. A running user server on that port will prevent this configuration from starting. Use a separate test port/config or coordinate a restart; do not accidentally run creation tests against the user's Gemini server. Use a separate test database.

Existing TEST-026 already covers keyboard opening, initial focus, provider disclosure, upload, status persistence, progress semantics and rescheduling. Add a focused responsive browser check only if layout changes introduce meaningful risk: assert no document overflow at the three widths and verify create/reschedule controls remain visible and operable. Screenshot inspection is necessary for design fidelity; passing DOM assertions alone is insufficient. Avoid tests that merely compare each CSS literal to itself.

Independent final verification should report which widths and states were actually observed and link captured evidence. This plan makes no assertion that visual, accessibility, build or Gemini checks have already passed.
